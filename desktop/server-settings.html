Сервер для России

Приложение может подключаться к вашему серверу MPOL в России без VPN. Сначала разместите серверную часть в российском облаке. Само изменение адреса не создаёт сервер.

Текущий сервер: —

Для сохранения существующих аккаунтов оба сервера должны использовать одну и ту же базу PostgreSQL. Нельзя вводить чужие адреса: пароли и переписки передаются выбранному серверу.

Открыть это окно можно в любое время сочетанием Ctrl + Shift + S.
