Как начать

Короткие инструкции для двух платформ.

⊞ Установка на Windows

  1. Нажми «Скачать установщик EXE».
  2. Открой скачанный MpolMessengerSetup.exe и следуй инструкциям.
  3. Запусти MPOL из меню «Пуск» или ярлыка, затем войди в аккаунт.
  4. Если сервер не отвечает, проверь интернет и подключение через VPN.
Файлы загружаются напрямую из официального GitHub Releases. При предупреждении Windows проверь источник и подпись файла перед запуском.

◧ Добавление на iPhone

  1. На iPhone открой сайт MPOL через кнопку «Открыть в Safari».
  2. В Safari нажми «Поделиться» (квадрат со стрелкой вверх).
  3. Выбери «На экран Домой» / «Добавить на экран Домой».
  4. Подтверди «Добавить», затем открой ярлык на главном экране.
Для микрофона и камеры разреши доступ в Safari. Звонки могут не приходить, когда браузер закрыт или телефон заблокирован.
