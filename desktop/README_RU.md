# MPOL Messenger Desktop 2.3.0 — Windows EXE без запуска Edge

Это **реальный Electron-клиент** существующего MPOL Messenger, а не новая демонстрация с пустыми чатами.

## Основное

- **Отдельное окно Windows**, запущенное собственным `MpolMessenger.exe`. Внутри находится Chromium из Electron 45.3.2; системный Microsoft Edge не запускается.
- Основной контент безопасно загружается с `https://mpol-messenger-api.onrender.com/`. Это **та же онлайн-база Neon**, те же аккаунты, группы, сообщения, заявки, друзья и файлы.
- Внутри уже используются оригинальные четыре WebP-иконки MPOL Black из `client/ui/icons/`: Сообщения → Друзья → Заявки → Поиск. Сервер отдаёт те же изображения, что в релизе 2.2.1.
- Поиск пользователей, заявки в друзья и индикатор новых заявок работают средствами существующего онлайн-клиента. Новый EXE не заменяет их пустыми заглушками.
- Собственная системная иконка, независимый от Edge сеанс, Ctrl+R для перезагрузки, F11 для входа/выхода из полноэкранного режима и Esc для выхода из полноэкранного режима.
- Запрос разрешения на микрофон, камеру и уведомления. Для показа экрана пользователь сам выбирает окно или монитор в системном диалоге.
- Встроенный диалог Windows «Сохранить файл» для файлов из переписок.
- При недоступном сервере отображается отдельный тёмный экран с кнопкой повторного подключения.

## Установка и сборка

### Скачать с GitHub

После успешного GitHub Actions релиз находится на:
`https://github.com/MOnarh-ja1/MpolMessenger/releases/tag/v2.3.0-desktop`

Загрузи `MpolMessenger.exe`, закрой прежний MPOL, запусти новый. Это **портативный EXE** (встроенный Chromium, один файл; он значительно больше прежних ~6,7 МБ). Возможны предупреждения Windows SmartScreen, поскольку файл пока не подписан платным сертификатом издателя.

### Собрать самостоятельно

Требуется Node.js 24 и интернет для первоначальной загрузки Electron:

```powershell
cd desktop
npm install
npm test
npm run dist:win
```

Файл: `desktop/dist/MpolMessenger.exe`.

## Безопасность

- `nodeIntegration:false`, `contextIsolation:true`, `sandbox:true`, `webSecurity:true`.
- Запрещена навигация внутри окна на посторонние сайты, неизвестные права и произвольные загрузки из других источников.
- Не предоставляется произвольный IPC к Node.js или Windows.
- Медиаустройства требуют разрешения пользователя.
- При первом входе может потребоваться снова ввести данные MPOL. Аккаунты и переписки **не удаляются**: сервер и база остаются прежними.
- Бесплатный Render может «засыпать» и запускаться с задержкой; для доступа к чатам необходим интернет.
- Протокол звонков в существующем сервере WebRTC всё ещё работает только через STUN, без своего TURN-сервера. Эта desktop-оболочка не гарантирует устранения потерь голоса при плохой связи.
- Данные не защищены сквозным шифрованием и приложение пока не прошло независимый аудит безопасности.
- Новый Electron EXE не заменяет физически уже установленные старые Go/Edge EXE. Их нужно закрыть и запустить скачанный файл. Старый автозагрузчик имеет ограничение на размер, поэтому серверный манифест не перенаправляется автоматически на тяжёлый Electron EXE.

## Список важных файлов

`desktop/main.cjs` — Electron main process с нативным окном и разрешениями.

`desktop/lib/security.cjs` — ограничения origin и внешних ссылок.

`desktop/offline.html` — экран переподключения.

`desktop/tests/security.test.cjs` — проверки безопасности.

`.github/workflows/electron-desktop-release.yml` — автоматическая Windows-сборка с публикацией EXE.
